# LesOS

**LesOS** — минималистичная операционная система на ассемблере и C++, загружаемая с дискеты (1.44 МБ). Демонстрирует базовые концепции ОС: загрузку в защищенный режим, управление памятью и простой текстовый интерфейс.

## Возможности

- 🔧 **Загрузчик** (512 байт): переход из 16-битного в 32-битный режим, загрузка ядра с диска
- ⌨️ **Простой shell**: интерпретация нажатий клавиш и вывод на экран
- 🖥️ **VGA текстовый режим**: прямой вывод в видеопамять (0xB8000)
- 🔌 **Serial I/O**: вывод на последовательный порт для отладки

## Архитектура

boot.asm Загрузчик, переход в protected mode kernel.cpp Основное ядро: обработчик клавиатуры, текстовый интерфейс kernel.ld Скрипт линкера для позиционирования ядра в памяти Makefile Сборка проекта

### Поток выполнения

1. **Boot** (`boot.asm`): BIOS загружает 512-байтовый сектор (0x7C00)
2. Загрузчик читает 32 сектора ядра (16 КБ max) с диска в память (0x10000)
3. Переключение в 32-битный защищенный режим через GDT
4. **Kernel** (`kernel.cpp`): инициализация serial/VGA, бесконечный цикл обработки прерываний клавиатуры
5. Текст выводится одновременно на VGA экран и serial порт

## Требования

- `nasm` — ассемблер для boot-сектора
- `g++ -m32` — 32-битный компилятор C++ (может потребоваться `gcc-multilib` на 64-битной системе)
- `qemu-system-i386` — эмулятор для запуска
- `make` — сборка проекта
